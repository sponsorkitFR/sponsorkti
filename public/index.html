💳 Stripe — Détection paiements

Quand une marque te paye via Stripe, le deal passe automatiquement à Payé. Configure le webhook Stripe pour activer cette fonctionnalité.

URL du webhook Stripe
Chargement...
Comment configurer :
1. Va sur dashboard.stripe.com/webhooks
2. Clique "Add endpoint" → colle l'URL ci-dessus
3. Sélectionne les événements : payment_intent.succeeded
4. Copie le "Signing secret" → ajoute-le dans Vercel comme STRIPE_WEBHOOK_SECRET
🔵 PayPal — Détection paiements

Même chose pour PayPal. Le deal passe automatiquement à Payé dès réception du paiement.

URL du webhook PayPal
Chargement...
Comment configurer :
1. Va sur developer.paypal.com
2. Créé une app → Webhooks → "Add Webhook"
3. URL : colle l'URL ci-dessus
4. Événements : PAYMENT.CAPTURE.COMPLETED
5. Ajoute PAYPAL_CLIENT_ID, PAYPAL_CLIENT_SECRET, PAYPAL_WEBHOOK_ID dans Vercel
